# 05. 결과물·보고서 구성

## 목적

과제에서 요구한 제출물 형식에 맞춰 분석 흐름과 핵심 근거를 전달합니다. 제출 형식과 필수 요구사항이 우선입니다.

## 프롬프트

```text
과제의 제출 요구사항을 우선 적용해 결과물을 구성해줘.
요구 형식이 별도로 정해지지 않은 경우에만 다음 흐름을 제안해줘.

1. 문제 정의 및 목표
2. 데이터 출처·범위·기간·전처리
3. 분석 지표와 방법, 선택 이유
4. 주요 결과와 근거
5. 결과 검증 및 대안 접근 비교
6. 결론과 실행 가능한 제안
7. 한계·가정·추가 데이터 필요

각 결론이 어떤 데이터·계산·문서 페이지에 근거하는지 연결해줘.
실제로 실행하거나 확인하지 않은 내용은 완료했다고 쓰지 말고,
미구현·미검증 항목을 분명하게 표시해줘.
```

## 보고서 품질 점검

- 문제와 결론이 직접 연결되는가?
- 지표의 정의와 단위가 명확한가?
- 비교 대상·기간·표본 수가 표시되어 있는가?
- 표와 그림이 본문 주장과 일치하는가?
- 상관관계를 인과관계로 단정하지 않았는가?
- 제한과 한계를 숨기지 않았는가?
- 과제에서 요구한 파일명·위치·형식을 지켰는가?
