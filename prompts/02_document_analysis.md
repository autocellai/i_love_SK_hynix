# 02. PDF 및 다량 문서 탐색

## 목적

문서를 처음부터 끝까지 요약하기보다 문서 구조를 먼저 파악하고 과제 관련 근거를 찾습니다.

## 1단계: 문서 인벤토리

```text
제공된 문서를 파일별로 조사해줘. 우선 내용 전체를 길게 요약하지 마.
각 파일에 대해 다음을 정리해줘.
1. 파일명, 형식, 페이지 수(가능한 경우)
2. 문서의 목적과 주제
3. 목차·주요 섹션
4. 표·그림·데이터가 집중된 페이지
5. 과제 요구사항과 관련성이 높아 보이는 부분
6. 검색·추출이 잘 되지 않는 페이지나 표
근거가 불확실하면 불확실하다고 표시해줘.
```

## 2단계: 질문 기반 페이지 탐색

```text
현재 확인하려는 질문은 {질문}이야.
문서에서 관련 내용을 찾아 다음 형식으로 정리해줘.
- 확인된 사실
- 원문을 찾은 파일명과 페이지 번호
- 수치·단위·기간·대상 범위
- 다른 문서와 일치하거나 충돌하는 내용
- 해석상 주의점과 추가 확인 필요
문서에 직접 쓰여 있지 않은 원인이나 결론을 추론해서 사실처럼 쓰지 마.
```

## 3단계: 표·수치 확인

```text
{문서명}의 {페이지/표}를 확인해줘.
표의 열·행 구조, 단위, 각주, 집계 기간, 대상 범위를 먼저 설명하고,
필요한 값만 추출해줘.
표가 깨졌거나 추출이 불완전하면 추정값을 채우지 말고 문제를 보고해줘.
```

## 문서 근거 기록

| 질문 | 문서·페이지 | 확인된 사실 | 수치·단위·기간 | 상태 |
|---|---|---|---|---|
| {질문} | {파일 p.#} | {내용} | {값} | 사실/추가 확인 |

## 주의사항

- PDF 텍스트 추출은 표의 열 정렬, 각주, 단위, 음수·소수점을 틀릴 수 있습니다. 핵심 수치는 원문 페이지에서 재확인합니다.
- 서로 다른 문서의 기간·대상·정의가 같다고 가정하지 않습니다.
- 문서가 대외비라면 허용된 작업환경 내에서만 처리합니다. 발췌문, OCR 텍스트, 요약도 외부 전송하지 않습니다.
