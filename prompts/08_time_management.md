# 08. 시간 부족 시 범위 축소

## 프롬프트

```text
남은 과제 시간은 {N}분이야.
현재 구현 및 분석 상태는 {상태 요약}이고 필수 제출 요구사항은 {요구사항}이야.

남은 작업을 다음으로 분류해줘.
- 반드시 완료해야 하는 필수 작업
- 시간이 허용되면 진행할 개선 작업
- 지금은 포기할 작업

제출 가능한 최소 결과를 먼저 확보하고,
계산 검증과 저장·제출 확인 시간을 남겨서 순서를 제안해줘.
포기하거나 검증하지 못한 항목은 결과물의 한계로 기록해줘.
```

## 시간 배분 원칙

1. 과제에서 필수로 요구하는 산출물을 먼저 확인합니다.
2. 핵심 데이터 확인과 최소 분석을 먼저 끝냅니다.
3. 핵심 수치 재계산 및 근거 확인 시간을 확보합니다.
4. 시각적 개선이나 부가 기능은 필수 작업 이후에만 진행합니다.
5. 마지막에는 파일 저장, 경로, 제출 완료 상태를 확인합니다.

## 하지 말 것

- 새 라이브러리나 프레임워크를 학습하느라 핵심 분석을 미루지 않습니다.
- 검증되지 않은 새 접근법을 종료 직전에 도입하지 않습니다.
- 제출 요구사항과 관계없는 기능을 추가하지 않습니다.
