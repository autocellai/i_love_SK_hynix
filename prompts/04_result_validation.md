# 04. 결과 검증·반대 가설·민감도 분석

## 목적

결과를 기대에 맞추지 않고 재현 가능한 근거로 확인합니다.

## 프롬프트: 독립 검증

```text
현재 분석 결과 {결과 요약}를 독립적으로 검증해줘.

1. 분석에 사용된 원본 파일·행 범위·기간
2. 적용된 필터·그룹 기준·제외 조건
3. 컬럼 타입·단위·결측·중복 영향
4. 계산식과 분자·분모·집계 단위
5. 동일 결과를 독립 계산으로 재현할 수 있는지
6. 다른 집계 방식 또는 하위 그룹에서도 결과가 유지되는지
7. 결과와 반대되는 설명 가능성
8. 현재 데이터로 확인할 수 없는 주장

기존 결론을 전제로 하지 마. 문제가 있으면 결과를 고치기 전에 원인을 보고해줘.
```

## 예상과 다른 결과가 나왔을 때

```text
분석 결과가 예상과 다르게 나왔어. 결과를 임의로 수정하지 말고
아래 순서로 점검해줘.
1. 동일 입력·조건으로 결과가 재현되는가?
2. 파일 범위, 기간, 필터가 맞는가?
3. 자료형, 단위, 결측치, 중복, 이상치에 문제가 있는가?
4. 분자·분모와 집계 기준이 맞는가?
5. 그룹별 표본 수나 구성 차이가 전체 결과를 바꿨는가?
6. 다른 지표·시각화·층화 분석에서도 같은 현상이 보이는가?
각 단계별 확인 사실, 의심 사항, 다음 검증 방법을 나눠서 보고해줘.
```

## 민감도 분석

```text
전처리·필터 선택에 따라 결론이 달라지는지 비교해줘.
시나리오 A: {기준 처리}
시나리오 B: {대안 처리}
시나리오 C: {가능한 경우 원본 결측 유지}
각 시나리오의 표본 수, 핵심 지표, 그룹별 결과를 비교하고
결론이 안정적인지 또는 처리 방식에 민감한지 알려줘.
```

## 검증 상태 구분

- **확인된 사실:** 원본 자료나 명시된 기록으로 확인
- **계산 결과:** 명확한 공식과 입력값으로 재현
- **가설:** 그럴듯하지만 직접 검증되지 않음
- **미확인:** 자료 부족·접근 제한·계산 불가
