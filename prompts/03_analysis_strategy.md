# 03. 분석 질문·지표·방법 선정

## 목적

분석할 문제를 관찰 가능한 질문과 계산 가능한 지표로 바꾸고, 대안 방법을 비교합니다.

## 프롬프트

```text
과제 목표는 {목표}이고 현재 확인된 데이터는 {데이터 요약}이야.

다음 순서로 분석 설계를 제안해줘.
1. 분석 질문을 1~3개로 구체화
2. 질문별 종속/결과 변수와 설명 변수 후보
3. 지표의 정의, 계산식, 분자·분모, 단위, 집계 단위, 기간
4. 가능한 분석 접근법 2~3개와 장단점
5. 데이터 요구사항과 결측·편향 위험
6. 추천 접근법과 선정 이유
7. 결과를 검증할 방법
8. 데이터만으로 결론 낼 수 없는 부분

실제 데이터에서 확인되지 않은 원인을 단정하지 말고,
관찰적 연관성과 인과관계를 구분해줘.
```

## 지표 정의 템플릿

| 항목 | 정의 |
|---|---|
| 지표명 | {예: 불량률} |
| 계산식 | {불량 수량 ÷ 검사 수량 × 100} |
| 분자 | {불량 수량} |
| 분모 | {검사 수량} |
| 단위 | {%} |
| 집계 단위 | {라인/제품/일자} |
| 기간 | {시작일~종료일} |
| 필터 | {제외 조건} |
| 주의점 | {표본 수·중복·결측 등} |

## 대안 접근 비교 템플릿

| 방법 | 얻을 수 있는 정보 | 장점 | 한계 | 선택 여부 |
|---|---|---|---|---|
| {방법 A} | {내용} | {장점} | {위험} | {선택/제외} |
| {방법 B} | {내용} | {장점} | {위험} | {선택/제외} |
| {방법 C} | {내용} | {장점} | {위험} | {선택/제외} |

## 분석 시 유의점

- 건수와 비율을 혼동하지 않습니다. 그룹별 분모가 다르면 비율과 표본 수를 함께 봅니다.
- 전체 평균이 그룹 구성 차이에 영향을 받을 수 있으므로 필요하면 제품·기간·공정 등으로 층화합니다.
- 상관관계, 시간적 선후관계, 인과관계는 서로 다른 주장입니다.
- 비교 기간과 데이터 정의가 일치하는지 확인합니다.
