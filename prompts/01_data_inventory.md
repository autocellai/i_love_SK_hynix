# 01. CSV 및 데이터 인벤토리·품질 진단

## 목적

분석하기 전에 데이터 구조와 품질을 파악합니다. 진단과 실제 전처리를 분리합니다.

## 프롬프트: 파일·스키마 파악

```text
코드와 원본 데이터는 변경하지 말고 제공된 데이터 파일을 조사해줘.

1. 파일명·형식·크기
2. CSV별 행·열 수
3. 컬럼명과 데이터 타입
4. 날짜·시간 컬럼의 범위와 형식
5. 식별자·측정값·범주형 변수 후보
6. 수치형 기초 통계 및 범주형 빈도
7. 파일 간 연결할 수 있는 키 후보
8. 분석 목적에 필요한 변수와 없는 변수

대용량 데이터를 전부 출력하지 말고 요약 통계와 필요한 일부 샘플만 보여줘.
```

## 프롬프트: 데이터 품질 진단

```text
@{데이터파일}에 대해 데이터 품질 진단을 수행해줘.

- 행·열 수와 컬럼별 타입
- 컬럼별 결측 개수와 비율
- 완전 중복 행 및 주요 키 중복
- 값의 범위·허용 범위를 벗어난 값
- 이상치 후보(탐지 기준을 함께 표시)
- 날짜 누락·비정상 순서·기간 편중
- 범주형 값의 오탈자·표기 불일치
- 결측치나 이상치가 특정 기간·그룹에 집중되는지

결과는 표로 요약하고, 분석에 미칠 수 있는 영향을 설명해줘.
삭제·대체·수정은 실행하지 말고 가능한 처리 옵션과 장단점만 제시해줘.
원본 파일은 변경하지 마.
```

## 결측치 판단 가이드

| 방법 | 검토할 상황 | 위험·주의점 |
|---|---|---|
| 결측 행 제외 | 결측이 적고 해당 행 제외가 분석 목적에 큰 편향을 만들지 않을 때 | 표본 손실, 특정 그룹 편향 |
| 평균 대체 | 수치형 변수에서 평균이 대표값으로 타당할 때 | 분산·관계 왜곡, 이상치 영향 |
| 중앙값 대체 | 치우친 분포나 극단값이 있을 때 | 분포 및 변동성 왜곡 |
| 최빈값 대체 | 범주형 변수에서 대표 범주 대체가 타당할 때 | 특정 범주 과대표현 |
| 결측 표시 유지 | 결측 자체가 의미 있거나 원인 미상일 때 | 분석 기법이 결측을 지원해야 함 |
| 결측 별도 범주 | 범주형 결측 여부가 유의미할 때 | 결측의 원인을 설명하는 것은 아님 |
| 그룹별 대체 | 그룹별 분포 차이가 뚜렷하고 근거가 있을 때 | 그룹 정의에 따라 결과가 달라짐 |

**원칙:** 결측률만으로 처리법을 결정하지 않습니다. 발생 메커니즘을 확인하고, 분석 목적에 맞춰 결정합니다. '결측이 무작위'라고 증명되지 않았다면 무작위라고 단정하지 않습니다.

## 처리 후 검증 프롬프트

```text
선택한 전처리 규칙 {규칙}을 별도 데이터에 적용해줘.
원본은 보존하고 처리 전후의 행 수, 컬럼별 결측률, 분포,
그룹별 표본 수, 핵심 지표 변화를 비교해줘.
처리로 인해 결론이 달라지는지 민감도 분석을 수행하고,
확인된 사실과 한계를 구분해줘.
```
