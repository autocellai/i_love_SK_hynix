# 09. 작업 이해도 및 후속 질문 대비

## 목적

참가자가 본인의 문제 정의, 도구 활용, 판단, 검증, 한계를 직접 설명할 수 있는지 점검합니다.

## AI 사용이 허용된 작업 단계에서의 자기 점검 프롬프트

```text
코드나 결과물을 수정하지 말고 내가 수행한 작업을 점검할 수 있도록 정리해줘.
1. 전체 처리 흐름을 5단계 이내로 요약
2. 핵심 파일·함수·분석 단계의 역할
3. 분석 방법을 선택한 이유와 고려한 대안
4. AI 제안을 수정하거나 채택하지 않은 부분과 이유
5. 결과를 검증한 방법과 검증하지 못한 부분
6. 가장 중요한 한계 3가지
7. 평가자가 질문할 만한 확인 질문 5개
실제 작업 기록에 없는 내용은 만들어내지 마.
```

## 후속 질문을 대비하는 답변 구조

- 왜 이 분석 방법을 선택했나요? → 문제 정의, 지표 적합성, 데이터 특성
- 다른 접근 방법도 검토했나요? → 대안, 장단점, 선택·제외 이유
- AI 제안 중 수정한 것은 무엇인가요? → AI 제안, 오류·한계, 직접 수정한 판단
- 정확하다고 판단한 근거는? → 데이터 품질, 계산 재현, 교차 검증
- 분석 결과의 한계는? → 표본·기간·누락 변수·인과관계·일반화 한계

## 중요: 시험 단계별 사용 제한

후속 서술형 단계에서는 AI, 복사·붙여넣기와 이 문서의 참고를 하지 않습니다. 본인이 실제 수행한 내용만 기억해 직접 답변합니다. 사전 학습용 구조로만 활용하세요.
