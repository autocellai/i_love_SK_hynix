# 09. 작업 이해도 및 후속 질문 대비

## 목적

참가자가 본인의 문제 정의, 도구 활용, 판단, 검증, 한계를 직접 설명할 수 있는지 점검합니다.

## AI 사용이 허용된 작업 단계에서의 자기 점검 프롬프트

```text
코드나 결과물을 수정하지 말고 내가 수행한 작업을 점검할 수 있도록 정리해줘.
1. 전체 처리 흐름을 5단계 이내로 요약
2. 핵심 파일·함수·분석 단계의 역할
3. 분석 방법을 선택한 이유와 고려한 대안
4. AI 제안을 수정하거나 채택하지 않은 부분과 이유
5. 결과를 검증한 방법과 검증하지 못한 부분
6. 가장 중요한 한계 3가지
7. 평가자가 질문할 만한 확인 질문 5개
실제 작업 기록에 없는 내용은 만들어내지 마.
```

## 설계·구현 서술형 예상 질문

AI 사용이 허용된 과제 풀이 단계에서 요구사항, 설계안과 실제 작업·검증 기록을 함께 제공해 사용합니다. 설계 초안과 구현 후 각각 점검하면 답하기 어려운 부분과 설계·실제 결과의 차이를 찾는 데 도움이 됩니다. 예상 질문은 연습용이며 실제 출제나 점수를 보장하지 않습니다.

```text
당신은 이 프로젝트의 설계와 구현을 평가하는 기술 면접관이자 채점자입니다.

아래 요구사항, 설계안과 실제 작업·검증 기록을 바탕으로,
설계자가 시스템을 실제로 이해하고 있는지 확인할 수 있는
서술형 예상 질문을 만들어 주세요.

질문은 단순한 기능 나열이나 용어 정의에 그치지 말고,
기본 구조와 처리 흐름을 설명하는 질문부터 설계 판단의 근거와 대안,
구체적인 상황에서의 동작과 결과까지 균형 있게 다뤄 주세요.
사용자가 명시하지 않은 조건도 검토하되,
설계에 없는 내용을 이미 구현된 사실처럼 전제하지 마세요.

다음 관점을 골고루 살펴보고, 프로젝트에 맞지 않는 항목은 제외하세요.

1. 전체 구조와 책임
- 주요 단계와 모듈이 어떤 순서로 연결되는가?
- 데이터와 상태는 누가 소유하고 갱신하는가?

2. 설계 선택과 대안
- 왜 이 구조를 선택했는가?
- 다른 방법과 비교했을 때 얻은 것과 감수한 비용은 무엇인가?

3. 사람·상태·시간의 조합
- 같은 역할의 사용자가 여러 명이면 어떻게 되는가?
- 작업 중 입력이나 조건이 바뀌면 어떻게 되는가?
- 요청이 중복되거나 순서가 바뀌면 어떻게 되는가?

4. 실패와 복구
- 각 단계에서 서버, 통신, 저장이 실패하면 무엇이 남는가?
- 재시도·재시작 시 중복이나 부분 결과는 어떻게 처리하는가?

5. 정확성과 검증
- 결과가 올바르다는 것을 어떤 독립적인 방법으로 확인하는가?
- 어떤 테스트를 실제로 수행했고, 어떤 상황은 아직 검증하지 못했는가?

6. 한계와 개선
- 현재 구조가 전제하는 조건과 가장 취약한 지점은 무엇인가?
- 규모가 커지거나 전제가 깨지면 무엇을 다시 설계해야 하는가?

각 질문은 아래 형식으로 작성해 주세요.

[예상 질문]
실제 평가에서 나올 법한 자연스러운 서술형 질문

[출제 의도]
채점자가 확인하려는 이해와 판단

[답변에 포함할 핵심]
빠뜨리면 안 되는 내용 3~5개

[현재 설계의 답변 가능 상태]
- 답변 가능: 설계에 근거가 있음
- 추가 확인 필요: 설계에 명시되지 않았거나 근거가 부족함
- 미구현·미검증: 구현 또는 실행 증거가 확인되지 않음

[설계 보완이 필요한 부분]
질문에 답하려면 결정하거나 검증해야 할 사항

가장 중요한 질문 5개를 먼저 제시하고,
그다음 빠뜨리기 쉬운 질문을 추가해 주세요.
설계에 없는 기능이나 실행하지 않은 테스트를 지어내지 말고,
판단의 근거가 된 설계 내용이나 기록도 짧게 밝혀 주세요.
설계상 계획과 실제 구현·실행 결과를 구분하고,
기록이 없으면 미구현으로 단정하지 말고 확인되지 않았다고 표시해 주세요.

[요구사항과 설계안]
여기에 붙여 넣기

[실제 작업·검증 기록]
여기에 붙여 넣기. 아직 없다면 없다고 표시
```

## 후속 질문을 대비하는 답변 구조

- 왜 이 분석 방법을 선택했나요? → 문제 정의, 지표 적합성, 데이터 특성
- 다른 접근 방법도 검토했나요? → 대안, 장단점, 선택·제외 이유
- AI 제안 중 수정한 것은 무엇인가요? → AI 제안, 오류·한계, 직접 수정한 판단
- 정확하다고 판단한 근거는? → 데이터 품질, 계산 재현, 교차 검증
- 분석 결과의 한계는? → 표본·기간·누락 변수·인과관계·일반화 한계

## 중요: 시험 단계별 사용 제한

후속 서술형 단계에서는 AI, 복사·붙여넣기와 이 문서의 참고를 하지 않습니다. 본인이 실제 수행한 내용만 기억해 직접 답변합니다. 사전 학습용 구조로만 활용하세요.
