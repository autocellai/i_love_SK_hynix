# 최종 제출 체크리스트

## 요구사항·파일

- [ ] 과제의 필수 요구사항을 다시 확인
- [ ] 제출 파일명·형식·저장 위치 확인
- [ ] 필수 파일이 모두 존재하는지 확인
- [ ] 결과물에서 실제 구현·분석 범위를 정확하게 설명
- [ ] 원본 데이터와 불필요한 임시 파일을 제출물에 포함하지 않음(과제 지시 우선)

## 분석·근거

- [ ] 핵심 지표의 정의·분자·분모·단위 확인
- [ ] 핵심 수치 재계산 또는 교차 검증
- [ ] 표·그래프와 본문 수치가 일치
- [ ] 문서에서 가져온 내용은 파일명·페이지 근거 확인
- [ ] 사실·계산 결과·가설·미확인을 구분
- [ ] 결측치·이상치 처리 방법과 영향 기록
- [ ] 한계와 추가 검증 필요사항 명시

## 코드·실행

- [ ] 실행 방법이 실제 환경에서 확인되었는지 확인
- [ ] 가능한 범위에서 테스트 실행 및 결과 기록
- [ ] 에러·미검증 항목을 숨기지 않음
- [ ] 파일 저장 상태 확인

## 보안·제출

- [ ] 과제 파일·데이터·결과물을 외부로 전송하지 않음
- [ ] Git Push하지 않음
- [ ] 승인되지 않은 도구나 모델을 사용하지 않음
- [ ] 제출 버튼·최종 완료 상태를 확인
- [ ] 후속 서술형은 운영 규정에 따라 직접 작성

## 마지막 5분

1. 제출 형식과 파일 경로를 확인합니다.
2. 가장 중요한 수치와 결론의 일치 여부를 봅니다.
3. 저장 여부와 제출 완료 메시지를 확인합니다.
4. 미검증·미구현 사실을 과장하지 않습니다.
