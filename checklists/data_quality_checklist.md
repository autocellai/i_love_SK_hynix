# 데이터 품질 체크리스트

## 파일 및 스키마

- [ ] 파일 형식·크기·행·열 수 확인
- [ ] 컬럼명과 데이터 타입 확인
- [ ] 날짜·시간 형식, 시간대, 기간 확인
- [ ] 수치 단위와 측정 기준 확인
- [ ] 식별자 및 중복 키 확인
- [ ] 파일 간 연결 키와 조인 관계 확인

## 결측치

- [ ] 컬럼별 결측 개수와 비율 계산
- [ ] 결측치가 특정 기간·제품·라인·그룹에 집중되는지 확인
- [ ] 결측 발생 원인을 데이터나 문서에서 확인할 수 있는지 파악
- [ ] 결측 행 삭제가 특정 그룹을 과도하게 제외하지 않는지 검토
- [ ] 평균·중앙값·최빈값 대체가 분포와 관계를 왜곡하지 않는지 검토
- [ ] 분석별로 결측 유지·제외·대체의 민감도 비교

## 중복·이상치·범위

- [ ] 완전 중복과 주요 키 중복을 구분
- [ ] 값의 허용 범위 및 단위 오류 확인
- [ ] 이상치 탐지 기준을 명시
- [ ] 극단값이 오류인지 실제 사건인지 구분할 근거 확인
- [ ] 처리 전후 표본 수와 핵심 지표 비교

## 분석 적합성

- [ ] 지표의 분자·분모·단위·기간·집계 단위 명시
- [ ] 그룹별 표본 수와 분모 차이 고려
- [ ] 전체 결과와 하위 그룹 결과 비교
- [ ] 상관관계와 인과관계 구분
- [ ] 데이터에 없는 설명 변수를 임의로 추정하지 않음
- [ ] 독립 계산 또는 다른 방식으로 핵심 수치 교차 검증
