# 보안·도구 사용 체크리스트

시험 시작 전과 도구 사용 전에 확인합니다. 대회 운영 규정과 시험 화면의 최신 안내가 항상 우선입니다.

## 공개 레포·외부 도구

- [ ] 공개 GitHub 레포의 Clone/다운로드가 과제 수행에 허용된 상황인가?
- [ ] 공개 저장소인지 확인했는가?
- [ ] README, 라이선스, 의존성, 설치·실행 스크립트, 네트워크 동작을 확인했는가?
- [ ] 필요한 파일·함수만 사용하고 전체 결과물을 그대로 대체하지 않는가?
- [ ] 공개 Skill, MCP·Plugin을 사용할 경우 제공 환경의 승인 절차를 따르는가?
- [ ] 외부 브라우저 직접 접근 등 금지된 경로를 사용하지 않는가?

## 데이터 보호

- [ ] 원본 데이터·과제 파일을 외부 AI·개인 계정·개인 PC로 보내지 않는가?
- [ ] 문제·파일·작업 결과물의 외부 공유 및 Git Push를 하지 않는가?
- [ ] 개인 PC 파일을 시험 환경에 업로드하지 않는가?
- [ ] 원본이 아닌 집계표·그래프·요약문도 민감할 수 있음을 고려했는가?
- [ ] 공개 GitHub 레포에 실제 시험 문제·대외비·개인정보·분석 결과를 추가하지 않는가?
- [ ] 개인 API 키·비밀번호·토큰을 입력하거나 공개하지 않는가?

## AI·작업 환경

- [ ] 대회에서 허용한 모델만 사용하고 제한 모델을 피하는가?
- [ ] 개인 Claude Code 등 별도 AI 모델 연결을 사용하지 않는가?
- [ ] 승인되지 않은 외부 네트워크를 사용하지 않고, Computer Use 자동 조작은 사용하지 않는가?
- [ ] 감독·보안·파일 업로드 제한을 우회하지 않는가?
- [ ] 서술형 단계의 AI 사용 금지 및 복사·붙여넣기 제한을 지키는가?

## 파일·Git 작업

- [ ] 원본 파일을 변경·삭제하지 않는가?
- [ ] 변경 전 대상 파일과 작업 내용을 확인했는가?
- [ ] `git add -A` 등 무차별 stage를 피하는가?
- [ ] commit이 필요하면 민감 정보와 대용량 데이터가 포함되지 않았는지 확인했는가?
- [ ] Git Push를 하지 않는가?

## 의심되거나 막힌 경우

- 제한을 우회하지 않습니다.
- 오류 발생 시각, 화면 메시지, 수행 단계 등 허용된 정보만 기록합니다.
- 대회 플랫폼의 공식 문제 신고·지원 절차를 이용합니다.
