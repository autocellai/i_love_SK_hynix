# 근거 추적표

> 실제 문서명·데이터 값·민감 정보는 공개 GitHub 저장소에 저장하지 않습니다. 이 템플릿은 승인된 과제 작업공간에서 사용합니다.

| ID | 분석 질문/주장 | 출처 파일·페이지 또는 컬럼 | 확인한 사실/값 | 계산식·처리 | 검증 방법 | 상태 | 한계 |
|---|---|---|---|---|---|---|---|
| E-01 | { } | { } | { } | { } | { } | 사실/계산/가설/미확인 | { } |

## 작성 기준

- 문서 근거: 파일명, 페이지, 표·그림 번호를 기록합니다.
- 데이터 근거: 파일, 컬럼, 기간, 필터, 집계 단위를 기록합니다.
- 계산 근거: 공식, 분자·분모, 단위를 기록합니다.
- 검증 방법: 원문 재확인, 독립 계산, 교차 집계 등 실제 수행한 절차만 기록합니다.
