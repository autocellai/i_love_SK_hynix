# AI 협업 해커톤 플레이북

업무 문제를 정의하고 AI와 기존 도구를 활용해 결과를 만들며, 그 결과와 자신의 판단을 검증하기 위한 실전 참고 자료입니다. 개발자와 비개발자 모두 사용할 수 있습니다. 공개된 평가축을 바탕으로 한 연습용 해석이며 공식 채점 기준, 점수·합격 보장은 아닙니다.

**대회 운영 안내와 과제별 지시가 이 저장소의 모든 내용보다 우선합니다.** 제공 환경에 원래 있던 지침도 보존하고 적용하세요. 기능이나 반입의 허용 여부가 불확실하면 사용하기 전에 시험 환경 내 공식 안내 또는 운영팀에 확인하세요. 차단된 기능을 우회하지 않습니다.

## 사용 흐름

1. 안내를 읽고 목표·사용자·필수 결과·제약을 구분합니다. 요구사항을 질문할 공식 경로가 없다면 가정과 확인 필요 항목을 남깁니다.
2. 제한 시간과 중요도에 맞춰 입력부터 결과까지 이어지는 핵심 흐름을 먼저 만듭니다. 기존 도구와 직접 구현을 비교하고 실제 작업에 맞는 방법을 선택합니다.
3. AI에 작은 단위의 작업을 맡기고, 결과를 직접 살펴 수정하거나 수정하도록 지시합니다. 본인 판단과 AI 제안을 구분합니다.
4. 정상 사례와 중요한 예외를 검증하고 원문 근거, 확인 결과, 남은 위험을 기록합니다. 실행하지 못한 것은 미검증으로 표시합니다.
5. 제출 조건에 맞는 결과물을 확인합니다. 후속 서술형은 참가자가 AI 없이 직접 작성합니다. 서술형 단계에서 이 문서를 보거나 복사해 쓰지 않습니다.

## 평가축에 연결되는 행동

아래는 연습용 해석이며 공식 배점이나 비공개 채점 기준은 아닙니다.

| 축 | 관찰할 수 있는 행동 |
|---|---|
| 기술 | 결과물 실행, 주요 예외 검증, 유지보수와 보안 위험 점검 |
| 의도 | 목표·제약 정의, 도구와 AI 위임 선택, 결과 통제 |
| 인지 | 처리 흐름·선택 이유·실패 조건과 한계 설명 |
| 소통 | 요구·불확실성 확인, 우선순위 공유, 피드백 반영 |
